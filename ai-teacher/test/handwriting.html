Handwriting slow-motion test

Press a button and watch the pen. Every letter, number, symbol, graph label and arrow is drawn stroke by stroke: the pencil tip travels along each stroke, lifts (it goes pale) and moves to the next. Use the speed menu to slow it right down, and "Colour each stroke" to see the stroke order. Add ?selftest to run the automatic checks.
